# NFTMarket Gas Report v2

## 执行命令

```bash
forge test \
  --match-contract "NFTMarket(T2)?Test" \
  --no-match-test testFuzz \
  --gas-report \
  2>&1 | tee gas_report_v2.md
```

## v1 → v2 对比（NFTMarket 函数 Max，成功路径）

| 函数 | v1 Max | v2 Max | 节省 |
|------|--------|--------|------|
| 部署 | 2,151,404 | 2,210,412 | +59,008（immutable 略增部署） |
| `list` | 85,570 | **61,618** | **-23,952 (~28%)** |
| `buyNFT` | 96,298 | **92,147** | **-4,151 (~4%)** |
| `permitBuyNFT` | 125,595 | **119,281** | **-6,314 (~5%)** |

## 优化项

1. `tokenPrice` + `tokenSeller` 两个 mapping → `Listing` struct 打包为 **1 个 slot**
2. `list` 单次 struct 写入；`buyNFT` / `tokensReceived` 单次 `delete`
3. `erc20Token`、`erc721Token`、`owner` 改为 **`immutable`**（减少 SLOAD）
4. `buyNFT` / `tokensReceived` 内存缓存 `Listing`，减少 storage 读取
